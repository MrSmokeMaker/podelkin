# Changelog

Формат — Keep a Changelog; версии — семантическое версионирование.

## [0.1.0] — 2025-01-15

### Initial release

- **Core features**: каталог из 15 поделок с поиском (синонимы, фасеты),
  режим мастера с пошаговыми таймерами, запасы, списки покупок, калькулятор
  стоимости (прайс-бук + конвертация единиц), проекты, доски настроения,
  экспорт сводки.
- **PWA**: manifest, service worker (app shell + посещённые страницы офлайн),
  установка на мобильный.
- **Monetization hooks**: тарифы free/premium/admin, фича-флаги
  (`src/lib/feature-flags.ts`), мок-аутентификация, расширенная статистика
  и `.csv`-экспорт для Premium, лимиты досок 3/20, `PremiumBadge`, офлайн-синхронизация
  Premium (предкэш топ-50).
- **Docs**: README, CONTRIBUTING, план монетизации, roadmap, issue-шаблоны,
  CI, release-чеклист.
