# Roadmap — 6 месяцев

## M1 — MVP-стабилизация (месяцы 1–2)

1. Реальная авторизация (JWT) вместо мока: регистрация, вход, восстановление
   роли после оплаты — `getAuthUser` в `src/lib/auth.ts` уже спроектирован
   как точка замены.
2. PostgreSQL + Prisma вместо in-memory слоя: миграции, персистентность
   между перезапусками (контракт моделей сохранён).
3. Подключение YooKassa: чекаут + вебхук, переключение роли после оплаты.
4. Аналитика событий (`plan_view`, `upgrade_click`): транспорт в одном
   модуле, события уже размечены в коде.

*Why it matters: без персистентности и реальных платежей продукт — демо;
эти два пункта превращают его в бизнес.*

## M2 — Community (месяцы 3–4)

1. Пользовательские поделки: публикация своих мастер-классов с модерацией.
2. Комментарии и лайки в каталоге; «сделано по этому рецепту» с фото результата.
3. Импорт/экспорт данных пользователя (JSON) — переносимость и доверие.
4. Семейные/групповые доски: совместные подборки на тарифе Family.
5. PWA-пуши: «продолжить проект», «поделка недели» (re-engagement).

*Why it matters: UGC и социальные сигналы снижают стоимость контента
и удержание поднимают сильнее любой платной фичи.*

## M3 — Growth (месяцы 5–6)

1. A/B-программа из плана монетизации: бейдж, триал, копия экспорта —
   победители фиксируются в фича-флагах.
2. B2B-пилот «Studio»: сметы на группу, `.csv` для бухгалтерии, 3–5
   пилотных кружков.
3. SEO-рост: посадочные страницы под запросы «сколько стоит связать…»,
   генерируемые из прайс-бука и калькулятора.
4. Локализация EN + переключение валют прайс-бука.
5. Партнёрства с магазинами материалов: ссылки «купить список» с реферальной
   комиссией.

*Why it matters: проверенная unit-экономика B2C + первые B2B-чеки — база,
чтобы масштабировать маркетинг без риска сжечь бюджет.*
